# Exercícios de Java

Esse repositório reúne exercícios desenvolvidos durante o curso técnico de ADS para praticar lógica de programação com Java.



- Java

## Sobre os exercicios

São exercícios de nível inicial que desenvolvi durante as aulas para entender melhor a linguagem e praticar os conceitos básicos de programação.

Os exercícios trabalham entrada de dados, variáveis, operadores, cálculos, condições e outros conceitos de lógica.

## O que pratiquei

- Variáveis
- Tipos de dados
- Operadores
- Scanner
- Condicionais
- Cálculos
- Entrada de dados
- Lógica de programação
